1. `data/quests/*.json` is authoritative for plot, dialogue constraints and quest conditions.
2. Repository runtime files are authoritative for implementation state.
3. `/mnt/e/Hazemoor/game-bible/specs/hazemoor/` defines production slices and acceptance gates.
4. Obsidian stores distilled context, rationale, navigation and lessons; it never overrides repository evidence.

Never copy secrets or credentials into the vault.
